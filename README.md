# Нормфиз-тренажёр — как опубликовать сайт

Весь сайт — один файл `index.html` (стили и скрипты внутри). Шрифты подгружаются с Google Fonts.

## Вариант 1. Netlify Drop (самый быстрый, без регистрации кода)
1. Открой https://app.netlify.com/drop
2. Перетащи папку с `index.html` в окно браузера.
3. Получишь ссылку вида `https://<имя>.netlify.app`. Чтобы ссылка не пропала, зарегистрируйся (бесплатно) и привяжи сайт к аккаунту.

## Вариант 2. GitHub Pages (бесплатно, постоянная ссылка)
1. Создай аккаунт на https://github.com и новый публичный репозиторий, например `normfiz`.
2. Нажми «Add file → Upload files», загрузи `index.html`, нажми «Commit changes».
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://<твой-логин>.github.io/normfiz/`.

## Вариант 3. Открыть локально
Просто дважды щёлкни `index.html` — сайт откроется в браузере без интернета (без фирменных шрифтов).

## Как обновлять
Замени `index.html` новой версией (на Netlify — перетащи заново в раздел Deploys, на GitHub — загрузи файл поверх).

Прогресс карточек хранится в браузере (localStorage) у каждого пользователя отдельно.
